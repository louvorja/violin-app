# Áudios litúrgicos

Vêm com o programa e aparecem na Biblioteca de Mídia, na categoria
**Litúrgicos** (`src/config/LiturgicalAudios.ts`).

| Arquivo | Na biblioteca |
| --- | --- |
| `../sabbath-school/opening.mp3` | Abertura da Escola Sabatina |
| `../sabbath-school/five_minutes.mp3` | 5 minutos para a Lição |
| `../sabbath-school/one_minute.mp3` | 1 minuto para a Lição |
| `intercessory_prayer.mp3` | Oração Intercessória |
| `closing.mp3` | Encerramento do Culto |

`intercessory_prayer.mp3` e `closing.mp3` são **provisórios** (voz sintética do
espeak-ng): para trocar, basta substituir o arquivo com o mesmo nome. Os três da
Escola Sabatina são os mesmos que o Temporizador de Culto toca por padrão.

Vozes geradas com o ElevenLabs (plano gratuito) exigem crédito: registre
"Vozes geradas com elevenlabs.io" em `credit` no `LiturgicalAudios.ts`, que
aparece junto do nome na biblioteca.
